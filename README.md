# Spitzer Data desktop downloads

Official Windows and Mac installers for the full Spitzer Data workspace.

Download and installation help: https://spitzerdata.com/desktop

- Windows: run the installer; no administrator account is needed.
- Mac: open the disk image and drag Spitzer Data into Applications. One app supports Apple silicon and Intel.
- Sign in with your existing Spitzer Data account. An internet connection is required.

The initial release is unsigned on Windows and ad-hoc signed on Mac; it is not Apple-notarized. First launch may require an operating-system confirmation. Installation instructions are on the download page. The release includes SHA-256 checksums.
